## Русский язык
> Calclang - тестовый язык программирования для счета чисел и вывода их в консоль. Является исполняемым виртуальной машиной (CLVM). Имеет особенность от других языков программирования - вместо работы с регистрами или стеком, вы работаете с массивами данных.

### Возможности
Calclang имеет не так уж и много возможностей, а именно может:
1. Считать выражения
2. Выводить текст на экран консоли
3. Сохранять значения выражений в определенной ячейке памяти CLVM и обращаться к ним
4. Принимать вводимый пользователем текст.
5. Соранять определенные ячейки памяти в текстовом файле

### Коротко о компиляторе
clcomp компилирует из файлов с кодом ассемблерне файлы, после чего вызывает clasm, который уже превращает ассемблерный код в байт-код, следовательно, вы можете спокойно писать и на CLASM даже без clcomp

### Синтаксис ассемблера CLASM
Синтаксис CLASM тоже довольно прост, хоть пока и не поддерживает многих вещей.

Для обращения к ячейке вам нужно ввести название массива с данными (их 4, ax (16 битные целые числа), bx (32 битные целые числа), cx (64 битные целые числа) и scx (строки любого размера)) и номер ячейки через пробел: `ax 1`, `bx 3`, `cx 0`, `scx 2`.

Команды и их синтаксис:
- `0x01` - `print {константа из секций rdata или srdata}` - вывод в консоль константы
- `0x02` - `input {ячейка памяти одного из массивов}` - ввод с консоли значения, его присвоение одной из ячеек памяти
- `0x03` - `printmem {ячейка памяти CLVM}` - вывод информации из ячейки памяти
- `0x04` - `dup {ячейка памяти для дублирования}, {ячейка памяти для вставки}` - дублироване информации из одной ячейки в другую
- `0x05` - `add {ячейка памяти 1}, {ячейка памяти 2}` - прибавление к ячейке памяти 1 значение ячейки памяти 2
- `0x06` - `sub {ячейка памяти 1}, {ячейка памяти 2}` - отнимание от ячейки памяти 1 значение ячейки памяти 2
- `0x07` - `mul {ячейка памяти 1}, {ячейка памяти 2}` - примножение к ячейке памяти 1 значение ячейки памяти 2
- `0x08` - `div {ячейка памяти 1}, {ячейка памяти 2}` - деление от ячейки памяти 1 значение ячейки памяти 2

### Библиотеки
Библоиотек есть только 3:
1. stdio - библиотека для вывода не только обычного текста, но и форматированного
2. stdrand - библиотека для генерации псевдорандомных (по сиду) чисел
3. stdtime - библиотека для получения количества секунд с начала эпохи

### Формат байт-кода
Первые 4 байта - сигнатура 43 4c 56 4d (CLVM)

Далее идут метаданные: количество ячеек числовой 16-битной памяти для выделения системой (2 байта),
количество ячеек числовой 32-битной памяти для выделения системой (4 байта),
количество ячеек числовой 64-битной памяти для выделения системой (2 байта),
адрес секции rdata (1 байт) (0 - нет),
адрес секции srdata (2 байта) (0 - нет) и
адрес секции text (2 байта) (0 - нет)

Далее идет секция rdata, в ней располагаются числовые константы. После нее располагается секция srdata со строковыми константами
и секция text с основным кодом.

### Флаги компилятора
clcomp.exe:
- **-o {название файла}** - название выходного исполняемого файла (байт-код)
- **-i {название файла}** - название промежуточного файла (после препроцессора)
- **-s {название файла}** - название промежуточного файла (после перевода в ассемблер)
clasm.exe:
- **{название файла с кодом} {название выходного файла с байт-кодом}** - компиляция в байт-код исходного файла
calclang.exe:
- **{название файла}** - название файла для исполнения
